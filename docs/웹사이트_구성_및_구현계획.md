# EM-I-CLEAR 웹사이트 구성 및 구현계획

## 목표

응급의학혁신교육연구회(EM-I-CLEAR)의 비영리 목적과 활동을 알리고, 보건의료인과 일반인·보호자를 위한 검토된 응급의료 교육자료를 공개·배포한다.

## 공개 범위

- 한국어를 기본으로 하고 핵심 단체 소개는 영문으로도 제공한다.
- 단체명, 비영리 성격, 사업 분야와 공식 이메일만 공개한다.
- 대표자·회원 이름, 서명, 상세 주소와 세무서 제출자료는 공개하지 않는다.
- 로그인, 회원관리, 결제, 문의양식과 데이터베이스는 초기 버전에 포함하지 않는다.

## 메뉴 구성

1. 홈
2. 단체소개
3. 교육자료
4. 연구·프로젝트
5. 활동소식
6. 공개문서
7. EN

첫 화면의 대표 문구는 `더 나은 응급의료를 위한 교육, 연구, 혁신`으로 한다. 교육자료는 `보건의료인용`과 `일반인·보호자용` 진입경로를 분리한다.

## 교육자료 기본정보

- 제목과 요약
- 교육 대상과 주제
- 자료 유형
- 게시일, 최종 검토일, 다음 검토예정일
- 근거와 참고문헌
- EM-I-CLEAR 검토 완료 표시
- 의료정보 면책문구
- 웹 요약과 PDF 다운로드
- CC BY-NC-ND 4.0 이용조건

개인 작성자·검토자의 이름은 공개하지 않고 내부 검토기록으로만 관리한다. 초안 상태의 자료는 사이트 빌드에서 제외한다.

## 디자인 방향

- 현대적인 임상·연구기관 분위기
- 딥네이비, 청록, 코럴과 오프화이트 조합
- 넓은 여백과 명확한 제목 단계
- 환자나 아동의 스톡사진은 사용하지 않음
- 파형, 데이터와 임상 흐름을 연상시키는 절제된 도형 사용
- 모바일 우선 반응형 설계와 기본 웹 접근성 적용

## 기술 구성

- Astro 정적 사이트
- TypeScript와 별도 UI 프레임워크 없는 CSS
- Markdown/MDX 및 Astro Content Collections
- Pagefind 정적 검색
- 사이트맵, RSS, Open Graph와 Organization 구조화 데이터
- 코드 MIT 라이선스, 교육 콘텐츠 CC BY-NC-ND 4.0
